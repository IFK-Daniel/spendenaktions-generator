# Schriften

- `NotoSans-Regular.ttf`, `NotoSans-Bold.ttf`, `NotoSerif-Regular.ttf`
- Quelle: vom Grafiker bereitgestellt (`Medien/Noto.zip`).
- Lizenz: SIL Open Font License 1.1 (Google Noto Fonts) — freie
  Nutzung, Modifikation und Weitergabe, auch eingebettet in PDFs.
- Verwendet als Ersatz für die im Original-Flyer eingesetzten
  Schriften "Droid Sans" / "Droid Sans Bold" / "Droid Serif" (siehe
  `templates/flyer-print-front/template.config.js` für den
  Hintergrund). Die eigentlichen Droid-Schriftdateien lagen nicht vor;
  falls der Grafiker sie nachliefert, können sie hier 1:1 ausgetauscht
  werden, ohne dass sich an der Platzierungslogik etwas ändert.
